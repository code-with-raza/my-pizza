# Efficient Coding

- Inspect only files relevant to the requested task.
- Read existing code before making changes.
- Reuse existing components and dependencies.
- Make minimal, focused changes.
- Avoid repeating documented information.
- Do not scan the entire repository for small tasks.
- Run targeted tests and lint checks.
- Report results concisely.
- Ask before destructive operations or database schema changes.
